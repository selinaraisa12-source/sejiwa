# sejiwa
Sejiwa adalah aplikasi skrining kesehatan mental digital yang dirancang untuk membantu pengguna memahami kondisi emosional dan psikologis mereka secara mandiri. Di tengah hidup yang serba cepat  dan penuh tekanan, Sejiwa hadir sebagai ruang aman: lembut, tidak menghakimi, dan mudah diakses.
